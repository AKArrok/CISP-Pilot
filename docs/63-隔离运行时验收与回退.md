# 隔离运行时验收与回退

本记录对应2026-11-01本机工程验收，不是生产迁移、云部署或模型泛化结果。默认数据库保持原版本、只读；工程验证只创建新合成库或临时库。

## 可重复入口

- 完整本地隔离Python门禁：`.venv-win/Scripts/python.exe -B tests/run_isolated_suite.py`。
- 登录、重试、恢复、追踪及来源展示浏览器门禁：`.venv-win/Scripts/python.exe -B tests/run_browser_e2e.py`，需要已安装的项目Playwright与浏览器。
- 容器检查：先`docker info`，再`docker build --platform linux/amd64 --tag cisp-local-check .`，使用`tests/docker_runtime_smoke.py --image cisp-local-check --data-dir <全新合成目录> --evidence-dir <全新证据目录>`。已有目录拒绝复用，失败现场不覆盖。
- 审阅校准：`python -m scripts.audit_judge_calibration`，参数与预期非零状态见`evaluation/judge-calibration-v1/README.md`。非零不能触发自动付费重试。

官方`api.deepseek.com`请求由回答、简单路由及证据模型工厂统一应用`deepseek-flash`和`thinking.type=disabled`。离线payload测试覆盖预算内外两条工厂路径；其他供应商端点保留显式模型配置。实验付费次数与预算仍须单独确认，运行时策略不构成无限调用授权。

## 版本化来源与恢复

结构化来源使用locator和原文；双语embedding_text仅用于检索。测试资产目录独立，经过真实manifest与向量文件加载；测试向量为协议fixture，dense关闭。切换真实向量服务前须重建并验证对应索引，不能把fixture作为语义效果证据。当前没有向默认生产语料导入NIST控制。

工程变更可通过既有Git提交和镜像标签回退。数据恢复先在独立路径执行SQLite备份API，再恢复到另一份新库，逐表核对记录摘要、完整性与外键；本轮已有合成库验证记录。真实业务库切换或迁移另需备份、明确授权和上线验收，不自动执行降级迁移。

故障现场保留执行ID、失败阶段、原始回执和已知用量。外部调用无回执或用量时，总费用为未知；保存已知估算部分，停止后续分发。测试容器仅按本轮所有权标签清理；若清理未确认则保留待处理状态，不删除其他容器或数据。
