# 审阅分数与风险证据一致性

在第4版6/8的基础上，离线复现到一个额外契约缺口：若审阅器自己明确将某条来源支持风险判定为contradicted，却给source_support满分，原校验仍接受该自相矛盾的输出。新增保护：**仅当风险项明确标注dimension=source_support时**，contradicted与来源支持满分同时出现会判为无效，进入复查，不自动修改分数。

第一版修复错误地把所有矛盾都绑定到来源支持分数；同一冻结数据中的wrong_locator案例证明引用错误和正文来源支持可以分属不同维度。该版本将通过的样例误判为无效，保留于`consistency-audit.json`。缩小条件后，`consistency-audit-r2.json`恢复为原6/8，原始模型输出和评分未修改。

目标回归与现有评分契约共8项通过，Ruff通过；无真实模型调用。此保护只有在模型输出风险维度且自行识别矛盾时才生效。它不识别模型遗漏的两项语义错误，因此第5项8/8仍未通过，不可启用自动满分验收。之前额度已耗尽或因未知用量关闭；后续真实实验需冻结具体新方案及新额度。
