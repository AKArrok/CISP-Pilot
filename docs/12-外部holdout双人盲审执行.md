# 外部 holdout 双人盲审执行

## 当前结论

最终外部 holdout 仍是 `blocked`，不是 `passed`。2026-09-18 已冻结一套满足
100 题、与现有题库内容去重、Apache-2.0 许可可追溯的外部候选集；当前唯一
不可机器代办的硬阻断是两名已签署的独立人类审校者及后续裁决。不得用两次
模型调用代替两名人类。

2026-09-14 搜索到 `npcola/CISP` 中约 300 道公开题，但页面未展示可复用
许可证据，而且预览内容存在题目拼接、选项缺失等污染，因此不纳入外部
holdout。商业题库页面的“免费浏览”同样不等于允许批量复制和用于项目评测。

## 2026-09-18 外部候选集

候选源为作者维护的 `tihanyin/CyberMetric` 中 `CyberMetric-500-v1.json`，
Hugging Face 数据卡标注 Apache-2.0。原始文件 SHA-256 为
`b0dcf5cb0b51792e3134bec8cecadfe9c5ecc543fb5abfcece99f041066701a5`。

样本按 `sha256(原始序号:题干)` 升序确定性抽取，且在查看任何模型预测前，
以明确理由排除 4 道没有信息安全语境的题，再按同一顺序递补至 100 题。
冻结样本 SHA-256 为
`453b47042f9c7d38257c91fa83697d853d27a3735d1d113326bafbbc703e0e38`。
机械审计结果为：唯一 ID 100/100、内部近重复 0、与当前 1360 题重叠 0、
标签或预测字段泄漏 0。

该数据是英文通用网络安全题，不是 CISP 真题。因此最终结果衡量“跨题源且跨语言
的知识点归因泛化”，不能解释为 CISP 考试命中率。当前预评分门禁报告为
`blocked`：题源、许可、数量、去重和哈希检查均通过，但两名盲审者、双份标签和
人工裁决尚未完成。

## 冻结流程

1. 把获得许可的外部题目填入
   `tests/fixtures/profile_accuracy_external_source.template.json`；原始文件不得包含任何标签或模型预测。
2. 运行 `scripts/create_external_blind_review_packets.py`，生成 A/B 两份不同顺序的盲审包。
3. 两名审校者分别填写、签名和记录完成时间；两人完成前不得互看结果。
4. 运行 `scripts/create_external_adjudication_packet.py`，在两份独立结果冻结后生成裁决包。
5. 完成裁决后运行 `scripts/assemble_external_holdout.py`，组装并计算不可变哈希。
6. 只运行一次 `python tests/eval_profile_external_holdout.py --method dense`。

完整性门禁会拒绝：仅替换 ID 的现有题、题干近重复、外部集内部重复、不合法
知识点名称、标签与裁决域不一致、可下调的质量门槛、缺少互盲声明或缺少裁决记录。

### 审校包与裁决的来源绑定

裁决包 schema v2 固定原始题集 SHA-256、两位审校者 ID，以及 A/B 两份完整审校包
的 SHA-256。组装器会重新计算并逐项比对：题源改动、审校内容改动、审校者不一致、
裁决包中的独立标签与审校包不一致，都会拒绝冻结。最终 holdout 保存这组哈希；
评分器会从最终题目中剥离裁决新增字段，重建无标注源题集并复算题源哈希；同时要求
裁决版本、两名不同审校者、人工独立审校声明及审校包哈希链全部齐全，否则保持
`blocked`。源题模板若预置审校域、可接受知识点或审校/裁决备注字段，也会在生成盲审包时
被拒绝，避免把既有标签伪装成独立审校结果。

哈希只能发现内容不一致，不能证明某个 reviewer_id 背后确实是独立自然人，也不能替代
签名、许可核验或诚实填写盲审声明；身份与盲审过程仍须由项目负责人线下确认。自动化
工作流测试使用合成审校数据，只证明篡改会被拒绝，不构成任何泛化准确率证据。

## 开发集误差改进

Dense v3 把候选集从单纯 top-5 改为“dense top-5 ∪ 全目录强词面证据”，
并允许正确选项中唯一的强命中纠正知识域。开发集端到端准确率由 68%
提升到 74%，覆盖率由 94% 提升到 98%。这仍是开发集适配结果，不是外部泛化成绩。

## 无人工金标时的自动代理验收

由于两名独立人工盲审当前不可执行，2026-09-18 对同一冻结外部集补充了自动代理验收。
该报告只衡量外部覆盖率、路线冲突和语义不变扰动稳定性，不计算或暗示准确率。

真实 dense 后端可用率为 100%，但 100 道英文外部题全部为 `unverified`，接受覆盖率为
0%。dense 路有候选 56/100，TF-IDF 有候选 100/100，精确证据有候选 5/100；
三路冲突率为 57%，97 题只有一路支持，3 题有两路支持但仍未通过冲突或 margin 门槛。
这证明当前 `conservative-attribution-v3` 不支持英文跨语言归因，不能通过降低阈值把拒答
伪装成覆盖率。

语义不变扰动的候选知识点一致率分别为：选项换序 99%、统一小写 93%、添加答题指令
前缀 88%；对应状态一致率均为 100%，原因是所有题都保持拒答。去除正确选项文本后，
候选知识点一致率降至 53%，说明候选排序明显依赖正确选项内容。以上结果是稳定性和依赖性
诊断，不是知识点正确率。
