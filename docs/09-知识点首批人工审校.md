# 首批知识点人工审校

审校版本：`manual-v1-2026-09-12`。

结果：首批 246 条全部给出结论，其中 235 条启用、11 条剔除、26 条规范名称，
并修正应急响应、访问控制、风险评估等明显串线的父级。其余 261 条维持候选状态。

本轮范围是生成器标记为 `recommended=true` 的首批候选。审校不是把候选批量放行，
而是逐条给出 `active` 或 `rejected` 结论，并在 JSON 的 `review` 字段保留版本、决定、
理由和原名称。未进入首批的低证据标题保持 `candidate`，不会进入诊断选题和画像。

## 判定标准

- 保留：边界明确，能够形成至少一道独立判断题或场景题；
- 重命名：概念成立，但原课件标题缺少必要上下文或带编号、阶段话术；
- 修正父级：标题抽取状态跨章节串线，导致分类明显错误；
- 剔除：空泛标题、结论性陈述、课件话术，或与更准确候选重复。

可复现审校规则位于 `data_ingest/taxonomy_review.py`。运行：

```bash
python scripts/build_taxonomy.py --import-db
```

脚本会输出 active、rejected、candidate 数量。诊断查询只读取 `active` 标签，避免把
未审校或已剔除候选继续写入学习者画像。
