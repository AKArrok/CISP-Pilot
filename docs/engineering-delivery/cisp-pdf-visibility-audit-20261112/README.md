# PDF 遮挡文本只读审计

## 问题与目标

在先前的真实CISP课程PDF页面，视觉上显示案例B，但 `page.get_text()` 同时提取到被后画出的案例A。只验证文本与PDF提取层一致，不能证明它在可见原页存在；这种内容进入索引会污染检索证据。本轮目标是提供只读、可复现的遮挡候选提示，供核对原页，不自动改写资料、删除文字、重建索引或宣布原库干净。

## 基线和方法

基线 `c9e9dee3dc7950c8daf34e7b9cafd1d5fac26e11`，其 CI `43076148252` 成功。`data_ingest/parse_courses.py` 用 PyMuPDF `page.get_text()` 读取，不检查后绘制内容。新增 `scripts/audit_pdf_visibility.py`：对每个提取文本span，以非空白字形包围盒中心为采样点，检查是否有后绘制、填充不透明度至少0.99的矢量图形包围盒覆盖；默认至少80%字形中心被覆盖时报告span序号、字数和覆盖比例。CLI仅输出PDF物理页与候选span计数，不输出正文、不产生文件。该方法是**候选筛查**：包围盒不是实际绘制形状，不处理剪裁/蒙版、后绘制图像及透明叠色，不证明可见性，也不能将未报警视为真实干净。

## 验证和局限

合成PDF红灯为工具缺失；实现后4个测试覆盖后绘制不透明遮挡、先绘制背景、透明遮罩与低于阈值的部分遮挡；加现有表格切片14项共18 passed，Ruff通过。一次测试文件重复导入引起Ruff失败已修正并重跑。只读真实问题页：2个此前人工在原页核对的被遮挡文本span均被标出，该页共23个候选，余下候选是否真正不可见尚未人工标注；这不是召回率/误报率估计。另选17个此前核查相关页，检测器0页报警；不证明它们无其他形式的隐藏内容。相关私有样本结果保存在本机 `data/evaluation/cisp-source-conditions-20261112/pdf-visibility-sample.json`。可运行 `python scripts/audit_pdf_visibility.py <本机PDF路径> --page <物理页码>` 做局部核查。

零外部模型调用、零新增费用；没有修改默认语料和业务数据库。原有 `data/cisp_qa.db` SHA256 `3d6d78663b9378d8791f1692afcdd702c9476866d5458c3492f307766e9d5b62`。该检测器目前不自动接入建库，更不能据此改写生产知识库；未来需扩大不同PDF标注样本、测试矢量覆盖误报和后绘制图像等漏报，再决定安全接入或隔离方式。用户已明确要求持续至Codex额度用完，覆盖旧10%阈值；不得使用重置券，新的私人内容外发须明确授权。
