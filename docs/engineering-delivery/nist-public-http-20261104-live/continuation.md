# 公开语料完整应用链路预验

冻结三次用户请求：AC-2 共享账号首问、同一线程的兜底账号追问、新线程的无关 DNS 问题。调用注册、登录、线程创建、chat/stream、历史与追踪端点；使用 ASGI TestClient 进程内传输，没有启动 TCP 服务或云部署。路由、追问改写与回答使用真实官方 DeepSeek Flash，显式关闭思考、每调用最多一次尝试；KB 是八份公开 NIST 原文及检索元数据，SQL 为全新合成库。

三次请求均收到 done，trace 持久化完成且 conversation_commit=confirmed。首问检索 AC-2/IA-2，正确说明成员退出时更改共享认证器且共享账号并非一律禁止；追问真实执行 rewrite，改写为“不常用的兜底账号是否也要统一设置到期自动禁用？”，仍检索 AC-2 并保持兜底账号例外。两轮 SQL 历史为四条。无关 DNS 查询来源为空，进入 abstained_no_context，仅调用路由模型，不调用回答模型，SQL 历史两条。未出现路由或改写降级。

实际6次模型调度：route、answer、route、rewrite、answer、route。原始 LangChain LLMResult 回执及用量全部保留；这些不是 HTTP 线路上的原始 JSON 字节。费用保守估算0.0032844美元、无未知用量。按官方当前 Flash 峰时未缓存输入0.3美元/百万token及输出1.2美元/百万token估算，未使用缓存及非高峰折扣，因此不冒充账单实付；来源为[官方模型价格](https://api-docs.deepseek.com/quick_start/pricing/)，记录于 price-source.json。

独立离线审计检查冻结输入与执行器摘要、问题绑定、SSE完成、实际来源、引用结构、追问调用、成对历史、提交状态、预算与模型回执序列；通过。故障测试覆盖丢失done、历史不足、来源错配、未提交、未知费用、空用量和重复回执，连同回执预算测试共11项通过。Codex另对照原文检查两份答案与一份拒答，接受本轮开发范围；非独立人工金标，不作为泛化准确率。

范围限制：dense、重排、查询变体、向量记忆和证据子代理关闭；真实SQL短历史保留，索引向量仅为启动协议fixture。未降低相关性门限，但BM25-only路径没有dense分数，因此不证明dense相关性门禁效果。测试通过不是生产迁移、网络容量或向量语义质量结论。
