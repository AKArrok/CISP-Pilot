# CISP 出处身份校验与安全回退

2026-11-11。用户要求承接固定证据预检发现的出处缺失：三条回答缺来源名称，两次同模型AI审阅均漏检。此前预检问题、课程原文、回答及回执均留在本机忽略目录；本轮不外发课程文本、不调用模型、不修改默认库或索引。

## 目标及约束

只对模型明确选择的有效 `[资料N]`，根据同次检索到的来源与页码/结构化定位生成出处。没有编号、编号越界、已有出处不匹配或元数据缺失时，不猜测来源，保留原回答并附“出处未核实”提示。程序的身份核验不代表资料支持正文的所有主张，也不代表模型一定选择了正确证据；语义仍需分别评估。

## 实施与验证

`agents/sources.py` 新增基于显式编号的出处渲染与严格身份检查；`agents/graph.py` 对未核验来源增加提示及追踪事件；`server.py` 在模型流结束时输出实际最终回答中程序追加的部分，避免页面与SQL记录不一致。已有完整出处不被悄悄改写；无上下文的拒答和其他路径不自动添加引用。

执行 `.venv-win/Scripts/python.exe -m pytest tests/test_citation_identity.py tests/test_citation_layout.py tests/test_source_locators.py tests/test_evaluation_platform.py tests/test_evaluation_workspace.py tests/test_data_catalog.py -q`：77通过、1条既有依赖弃用警告。覆盖编号缺失、越界、来源错误、页码错误、合法内文编号、结构化定位，以及真实HTTP模型分片、提示和程序生成出处与SQL一致；Ruff通过。过程中的前一版测试21通过、相关回归22通过，日志留本机 `data/evaluation/cisp-course-preparation-20261111/`。

回放上轮20条固定片段回答时，严格的 `[资料N]` 身份协议识别0/20；原因是上轮预检提示使用自由格式且没有要求这种编号，不能把它称为真实应用失败率，也不能说本次修复了上轮三题。三项数据中台记录已追加“调查中”，没有标记修复。旧评审、原始失败和校验记录保持不变。

## 剩余工作与限制

此版本只在离线和模拟HTTP路径验证；尚未在用户批准的课程材料上以应用实际引用协议重新运行模型，也没有实际检索、多轮或未见封存题验收。真实请求内容与上轮已批准的固定消息不同，不能复用上次对具体外发内容的批准。后续先准备清晰的具体消息和预算，再根据用户批准范围复测；无编号时无法凭空补全来源，这是有意保留的可见缺口。
