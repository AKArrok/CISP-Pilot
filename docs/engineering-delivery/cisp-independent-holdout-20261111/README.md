# CISP 独立命题、隔离与历史审阅复核

## 目标与事前规则

用户要求准备独立封存题及明确的外发/费用审批材料，并处理两项审阅分歧、四项审阅截断。先固定规则再命题：使用本机既有 Ollama 模型，在仅监听 127.0.0.1 且禁用云模型的服务上运行；每题是独立请求，不提供开发题、历史回答或改动记录。每个 CISP 领域以哈希排序取一个候选课程片段，排除此前真实及离线检索过的来源页和父片段；不能根据模型表现挑题或改题。生成失败要保留，不能抽取替代题后只展示成功结果。10 个领域各 1 题，所有题及证据、提示词、模型和代码快照、完整内容哈希在测试前冻结。模型作者与被测 DeepSeek 分开，但选题语料同源；当前操作者兼组织者与审阅者，因此这是“独立模型命题 + 页级隔离”，不是独立机构命题、独立语料、独立人工金标或生产验收。

## 隔离和外发门槛

命题前不得运行被测模型、不得以此集调优。题集和证据仅保存在本地私有目录，禁止加入知识库或公开提交；冻结后须阻止覆盖，执行前校验哈希。实际检索若命中批准清单外的任一文本，在任何回答调用前停止，形成新的逐项审核清单。用户尚未批准新题或新片段外发；在审批之前只做本机工作，不调用 DeepSeek。

本机命题第一轮保留 10/10 原始输出；预检发现多题要求资料未提供的关系、原因或细节，因此整轮不用于验收。第二轮使用相同10个事前选定片段和一套统一改进的命题要求重新独立生成全部10题，不从两轮挑选题目；保留第一轮失败，第二轮须重新检查并事前冻结。
