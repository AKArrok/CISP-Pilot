# 语料版本与检索缓存隔离

共享缓存键原来只含查询、检索设置与域等信息；同ID资料正文或页码发生变化后，新检索器可能返回旧文本与旧引用位置。两个合成语料负例先复现2失败/1通过，未调用模型或访问业务库。

最小修复首次检索时计算规范化语料元数据的SHA256，加入缓存键；同一语料的字典插入顺序不同仍复用缓存，不同正文或页码得到独立缓存。指纹按实例只计算一次，不在每次缓存命中时重复遍历语料。无需清空旧Redis键，旧键按原TTL自然过期。

修复后缓存隔离及既有检索追踪共14项通过，Ruff通过，零付费调用。语料在实例生命期中视为不可变；相同语料但向量或学习重排模型权重单独变化的版本命名空间仍需另行处理，不把本修复声称为覆盖所有模型资产更新。
